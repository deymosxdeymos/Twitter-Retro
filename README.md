# Twitter Retro

A slopfork of [Sam Henri Gold's Twitter client](https://github.com/samhenrigold/Twitter), reskinned like Tweetie 2 and Twitter for iPhone circa 2012, keeping the modern X features worth keeping. Mostly written by AI coding agents, mainly for my own phone. Feel free to try it, but there's no support.

What changed and how to build it: [RETRO.md](RETRO.md).
